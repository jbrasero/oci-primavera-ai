# Support policy

This is a community demonstration project, not an official Oracle product.
Oracle does not provide support for this repository.

The authors and maintainers provide no guaranteed support, response time,
maintenance, upgrades, compatibility work, bug fixes, or security patches.
Questions and issue reports may be reviewed at the maintainers' discretion,
but opening an issue does not create a support obligation.

Before using the project, you are responsible for validating:

- compatibility with your OCI and Primavera Unifier environments;
- API availability, permissions, authentication, quotas, and service costs;
- data protection, security, compliance, backup, and audit requirements;
- all read and write operations in a non-production environment;
- the behavior of models, agents, MCP tools, and generated output.

Do not post credentials, tokens, customer documents, personal data, private
endpoints, or sensitive logs in GitHub issues. Follow [SECURITY.md](SECURITY.md)
for vulnerability reports.
