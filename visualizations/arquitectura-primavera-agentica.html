Primavera Agentica, de un vistazo

La persona conversa; el supervisor decide; MCP ejecuta lecturas controladas; Unifier conserva el dato oficial.

1. Interfaz

Navegador

Shell activo, conversación, tarjetas de agentes, contratos y alertas.

→

2. Supervisor

Backend Node.js

Mantiene el contexto y elige qué especialista necesita la petición.

→

3. IA

OCI GenAI / Responses

Comprende la intención, solicita herramientas y redacta la respuesta.

→

4. MCP

Proceso local por stdio

Ficha 360, salud, riesgos, costes, planificación, BPs y documentos.

→

5. Unifier

REST API V1 / V2

Fuente oficial de shells, BPs, Cost Sheet, Schedule y Document Manager.

Los datos vuelven por el mismo camino y se presentan como respuesta, evidencia o alerta.

Elige un recorrido

Ejemplo: “Dame la ficha 360 de P-0001”. La IA decide usar el workflow adecuado y devuelve una explicación con datos reales.

  1. PreguntaLa UI incorpora el shell activo.
  2. DecisiónEl supervisor selecciona Ficha 360.
  3. LecturaMCP encadena REST V1 y V2.
  4. RespuestaLa IA resume evidencia y resultado.

Ejemplo: cada mañana revisa P-0001. Este recorrido es determinista: no necesita que la IA decida qué leer.

  1. ProgramaEl scheduler despierta a la hora configurada.
  2. FotografíaMCP consulta coste, plan, BPs y aprobaciones.
  3. ComparaEl backend contrasta con la línea base local.
  4. AlertaSolo avisa si existe un cambio relevante.

Ejemplo: contrato y anexos se convierten en un borrador revisable. Nada se publica sin validación humana y confirmación.

  1. DocumentosEl usuario selecciona contrato y anexos PDF.
  2. ExtracciónLa IA propone campos, partidas y conflictos.
  3. RevisiónUna persona corrige y resuelve bloqueos.
  4. PublicaciónMCP crea el BP y adjunta PDFs e historial.

Dónde queda cada cosa

Navegador

Shell activo, identificador de conversación e historial contractual todavía no publicado.

Backend local

Configuración segura, línea base y alertas operativas del Autopilot.

Primavera Unifier

Dato corporativo oficial; contratos publicados y su historial PDF + JSON.

Las consultas son de solo lectura. Las escrituras permanecen bloqueadas salvo habilitación y confirmación explícitas.
